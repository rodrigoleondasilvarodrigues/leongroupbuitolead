# Abra primeiro — Leon Group no VS Code

Esta é a pasta completa do projeto. Ela já reúne histórico, documentos, fontes, artes oficiais, explorações anteriores e scripts de produção.

## Como abrir

1. Abra o arquivo `ABRA-LEON-GROUP.code-workspace` no VS Code.
2. Abra o Claude Code no painel do VS Code ou no terminal integrado, conforme a instalação existente.
3. Na primeira conversa com o Claude Code, envie a mensagem abaixo.

## Primeira mensagem

Leia integralmente o arquivo `ENTREGUE-AO-CLAUDE-CODE.md`. Depois siga a ordem de auditoria indicada nele, leia o histórico e inspecione os materiais existentes. Quando tiver compreendido o projeto, produza você mesmo o `CLAUDE.md` ideal para gerenciar continuamente a Leon Group. Não recrie entregas concluídas e diferencie a identidade atual das explorações históricas.

## Arquivos de entrada

- `ENTREGUE-AO-CLAUDE-CODE.md`: briefing principal e instruções para a auditoria.
- `claude-context/`: conversa completa, estado, decisões, aulas, fontes e inventário.
- `outputs/LEON-GROUP/`: materiais oficiais atuais.
- `outputs/`: variações e explorações históricas.
- `work/`: scripts e textos-fonte usados na produção.

## Importante

Não há um `CLAUDE.md` pronto nesta pasta. O próprio Claude Code deve criá-lo depois de ler e conferir o conteúdo. Senhas e outros segredos foram removidos do histórico.
